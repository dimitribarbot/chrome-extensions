# Custom Chrome & Brave extensions repository

This is a repository holding custom extensions for Chrome & Brave browsers.

## nextjs-image-extractor

An extension allowing the replacement of the current NextJS image url with the real underlying image url.
For instance, it will replace:  

https://example.com/_next/image/?url=https%3A%2F%2Fwww.gimp.org%2Fimages%2Ffrontpage%2Fwilber-big.png&w=1536&q=75  

with:  

https://www.gimp.org/images/frontpage/wilber-big.png
